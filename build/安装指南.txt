Kiro Manager Lite - macOS 安装指南与常见问题
================================================

推荐：改用 .pkg 安装包
----------------------
同一版本在官方 Releases 页面同时提供 .pkg 和 .dmg，推荐下载 .pkg：
  - 双击后按系统“安装器”的向导一路继续，应用自动装进“应用程序”文件夹，不用拖动；
  - 装好后打开应用不会再提示“已损坏，无法打开”。
  - 首次双击 .pkg 如提示“无法验证开发者”，打开“系统设置”→“隐私与安全性”，
    在页面下方点击“仍要打开”，再按向导安装即可。这一步只在安装时需要一次。


用 DMG 安装的步骤
-----------------
1. 在“苹果菜单”→“关于本机”查看芯片类型：
   - Apple M 系列芯片：下载文件名带 arm64 的安装包
   - Intel 芯片：下载文件名带 x64 的安装包
2. 打开 DMG 后，把左侧的“Kiro Manager Lite”拖到右侧的“应用程序(Applications)”文件夹。
3. 从“启动台”或“应用程序”文件夹启动 Kiro Manager Lite。


重要：首次打开被拦截是正常现象，不是安装失败
--------------------------------------------------
本应用未做 Apple 付费签名与公证，macOS 的安全机制(Gatekeeper)会在首次打开时拦截。
这不代表软件损坏或安装失败，按下面任一方法放行即可正常使用。


情况一：提示“无法验证开发者”“来自身份不明的开发者”
----------------------------------------------------
方法 A（推荐）：
  1. 打开“应用程序”文件夹，找到 Kiro Manager Lite。
  2. 按住键盘 Control 键并点击该应用图标（或用触控板双指点按）。
  3. 在弹出菜单中选择“打开”。
  4. 在再次弹出的提示中点击“打开”确认。
  之后就能像平常一样双击启动了。

方法 B：
  1. 直接双击应用，出现拦截提示后不要删除。
  2. 打开“系统设置”→“隐私与安全性”。
  3. 在页面下方找到关于 Kiro Manager Lite 的提示，点击“仍要打开”。


情况二：提示“已损坏，无法打开，应将其移到废纸篓”
--------------------------------------------------
这是下载文件被系统加上“隔离属性”导致的，同样不是文件真的损坏。
最省事的办法是改用同版本的 .pkg 重新安装一次（会直接覆盖，数据保留）。
也可以手动处理：先确认安装包来自官方 Releases 页面，然后：

  1. 打开“终端”(Terminal)。
  2. 粘贴并执行下面这条命令（连同引号一起复制）：

     xattr -cr "/Applications/Kiro Manager Lite.app"

  3. 执行后重新打开应用即可。

说明：该命令只移除“这个应用”的下载隔离属性，不会关闭系统的全局安全功能，
      也不需要输入密码之外的任何额外操作。


安全提示
--------
- 请只从官方 Releases 页面下载安装包，不要运行来源不明的二次打包版本：
  https://github.com/lucks-cloud/kiro-manager-lite/releases
- 不要为了安装本应用而全局关闭 macOS 的安全防护(SIP / Gatekeeper)。
  上面的放行方式都只针对本应用单个文件，足够使用。


仍然无法安装或启动？
--------------------
到官方 Releases 页面提交 Issue，并附上：系统版本、CPU 架构(arm64 / x64)、
下载的安装包文件名、报错截图和操作步骤。请勿粘贴 Token、Refresh Token 或 API Key
等敏感信息。
